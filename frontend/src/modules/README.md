# 前端模块

- `00-auth`：登录。
- `04-file-transfer`：文件快传与公开分享页。
- `05-data-generator`：电话号码和身份证测试数据生成。
- `05-image-tools`：图片处理。
- `06-json-tools`：JSON 对比与格式化。
- `07-codec-tools`：文本转码。
- `06-integrations`：Webhook 集成。
- `08-learning`：Python、HTTP 与接口自动化能力路线、关卡证据、计时、卡点和自动笔记。
- `09-api-workspace`：接口记录、调试和酒店练习项目。
- `10-user-management`：用户与权限。
- `11-test-packages`：测试包上传、二维码和下载页。
- `12-command-library`：常用命令手册。
- `13-effects`：临时效果制作与公开效果页。
- `14-jenkins`：Emote APK 构建入口。
- `15-online-preview`：Emote 分支预览与同步状态。
- `16-ui-automation`：Emote UI 自动化用例、执行证据和失败诊断。
