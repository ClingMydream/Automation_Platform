# 个人工作台使用与验收

## 从哪里开始

- **我的工作 → 今日工作台**：查看真实待办、到期提醒、最近笔记、继续学习与实践结果。
- **我的工作 → 待办与备忘**：新建事项、设置提醒、标记完成；备忘可转换成笔记。
- **知识空间 → 笔记本**：Markdown 与代码块、笔记本标签（例如 `笔记本:Python`）、置顶、搜索、附件和回收站。保存失败保留输入；未提交草稿按账号留在本机。附件单个不超过 10MB。
- **知识空间 → 学习路线**：七个章节覆盖 Python、HTTP、接口、UI 和性能。示例、练习和参考答案可自由查看，不强制解锁。基础内容手动确认已练习，自动化章节的“已验证”必须关联自己真实通过的执行。
- **测试中心 → 实践实验室**：进入订单与库存练习子项目，运行固定测试工程，查看逐项结果与下载简短报告。

原来的工作手记、自考题库、Emote 测试与效率工具继续保留。已下线的旧学习、酒店练习和审批网页版没有恢复。

## 订单与库存练习

每个平台账号拥有独立 SQLite 业务数据库，不操作真实商品或真实用户库存。主平台继续使用原数据库结构，新增个人记录、附件、学习进度与执行记录表。

固定练习账号：`learner`（普通用户）、`lab_admin`（商品管理员），练习密码均为 `Practice123!`，与平台登录密码无关。

完整业务：查看商品 → 下单 → 库存扣减 → 查看订单 → 取消订单 → 库存恢复。管理员还可新增商品、按版本调整库存、查看操作审计。金额以整数分存储；重复请求幂等；并发下单不得超卖；重复取消只恢复一次库存。

接口文档：`/api/practice/docs`；OpenAPI：`/api/practice/openapi.json`。业务接口统一为 `/api/practice/v1`，使用独立练习 Token；平台 Token 不能代替练习 Token。

“工程与数据”可下载真实 pytest / Playwright / Locust 工程、查看规则并重置自己的固定数据。重置只影响个人业务库，会使旧练习 Token 失效，不删除笔记与测试历史。执行中禁止重置。

## 测试执行与报告

- 接口工程：鉴权与角色、下单与取消、幂等、参数与版本冲突、并发防超卖、Python 金额示例。
- UI 工程：真实页面下单、取消、库存恢复，保留视频与关键截图。
- 性能工程：只读商品查询，最多 5 用户、30 秒，展示请求数、失败数、RPS、P95 和平均响应。
- 固定目标为自己的练习子项目，不接受任意命令或线上地址。队列受限，执行器资源上限 640MB / 1 CPU。
- 支持停止、刷新恢复状态、历史回看、原始证据和 Markdown 简报。执行器不可用会明确显示未启动或失联，不会生成通过结果。
