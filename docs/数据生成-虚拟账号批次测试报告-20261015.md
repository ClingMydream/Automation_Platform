# 数据生成：虚拟号码与批次管理

实施日期：2026-10-15。仅本地改造，未推送、未部署。

## 行为

- 手机号生成统一使用 TEST-PHONE- 加 32 位大写十六进制字符，不生成真实手机号，不支持真实手机号格式校验或短信收发。
- 旧 cn_format、twilio_magic、configured_receivers 参数兼容接收，但全部返回虚拟测试标识，不读取真实号码池。
- 生成结果每条可填写备注；保存时填写批次名称及可选批次备注。
- 页面下方“已保存的虚拟账号批次”支持名称、号码、备注查询；查看、编辑、新增账号、移除账号、整批删除。
- 保存后必须点击“查看 / 编辑”修改原批次。“载入 / 导出”只载入副本，保存当前批次会另存新批次。
- CSV、JSON 包含账号备注。身份证生成保留原有行为。
- 新增 generated_phone_batches 表，按登录账号隔离；不删除或迁移已有数据。
- 保存幂等、修改版本冲突保护、删除确认。真实手机号、重复号码、空批次、空名称均拒绝保存。

## 验证结果

- 后端 11 项通过：原身份证校验、全部手机号模式安全、持久化增删改查、中文备注查询、备注修改、账号隔离、重复提交、版本冲突、非法输入及未登录拦截。
- 前端生产构建通过。
- Playwright 隔离页面流程通过：生成、批次保存、填写备注、再次编辑、新增账号、载入及删除；未捕获页面异常为 0。
- 390px 截图：output/playwright/data-generator-mobile.png；表格自身横向滚动。
- 页面自测使用模拟客户端，后端使用独立 SQLite 数据库；尚未验证远程 MySQL、线上重启与真实账号页面操作，不记作通过。

## 使用限制

虚拟测试标识不能直接用于要求 11 位真实手机号的业务，需要测试环境提供 Mock 或白名单。不可声称任意随机的真实格式手机号一定无人使用。
