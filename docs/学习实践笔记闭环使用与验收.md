# 学习、实践与笔记衔接：使用说明与验收

## 已上线的流程

应用版本 `ea84f60` 已推送并部署：https://xiaomeiqaq.top/ 。

1. 在“学习路线”选择章节。每章现在有目标、操作步骤、需要留下的结果、参考检查目标与下一步建议。
2. 点击“进入本章参考验证”，实验室会带上章节和工程类型，不再从空白入口重新选择。基础章节可先在本机运行示例，也可了解练习实验室。
3. 点击“开始测试”，等待固定参考工程实际结束。刷新只恢复状态，不会重复启动。报告显示中文检查名称、失败方向和验证范围。
4. 点击“带回本次执行与心得记录”，回到原章节。原先输入的心得草稿会保留，并关联真实执行；失败记录也可带回用于排错，但不能标记为已验证。
5. 写下自己的观察，选择学习状态，点击“保存心得并生成笔记”。笔记包含章节目标、自己的心得、参考示例、实际检查摘要和可返回的链接。已有笔记不会自动覆盖，另存需明确确认。
6. 首页会显示完成数量并继续指向尚未完成的章节。完成需要有效关联笔记；自动化章节还需要对应参考检查通过。没有硬性解锁限制。

## 判定与保留规则

- 基础章节使用“已练习”，由本人确认运行过程，不自动判定掌握程度。
- 自动化章节不再仅检查suite与passed状态：还要求包含本章对应的通过检查项。性能参考验证要求有效请求数大于0且失败数为0。
- “已验证”指平台固定参考工程覆盖了本章检查，不代表你本机改写的代码已经通过评测。
- 旧学习记录不删除。旧记录若不足以满足新的完成条件，会保留原内容，提示补充验证。
- 生成笔记使用按账号隔离的幂等编号；响应丢失后刷新重试不会重复创建。已经编辑或删除的笔记不会被旧请求覆盖。
- 笔记内部链接在当前标签打开，保留仅会话登录的身份；外部链接继续使用独立安全窗口。
- 本轮没有新增数据库字段、删除表或执行数据迁移。
