# UI 自动化环境管理

已部署应用版本：`dbb6433`。入口：Emote UI 自动化 → 执行环境 → 管理测试环境。

- 配置环境名称、Base URL、默认视口（手机/桌面）、选填备注；支持新增、列表读取、修改和删除。
- 配置保存在服务器新增表 `ui_automation_environments`，与测试账号分开维护。名称唯一；地址沿用既有目标地址校验，拒绝内网地址和 URL 内的账号密码。
- 页面工具栏可以直接选环境；浏览器记住最近选择，刷新后恢复。选择环境会使用其默认视口，执行前仍可临时调整视口。
- 保留内置平台预览；保存环境地址留空也使用平台预览。删除当前选择的环境后回到内置平台预览。另一浏览器删除环境后，陈旧执行请求返回明确 404，不会偷偷改用其他地址。
- 后端按 `environment_id` 读取执行目标，并再次校验地址。保存环境和临时 `target_url` 不能同时指定；旧调用方式仍兼容。
- 每次执行保存环境快照；后续修改或删除环境不改变历史报告。Runner 回调保留该快照。

API（沿用 UI 自动化导航权限）：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/api/v1/ui-automation/environments` | 列表 / 新增 |
| PUT / DELETE | `/api/v1/ui-automation/environments/{id}` | 修改 / 删除 |
| POST | `/api/v1/ui-automation/studio/runs` | 增加可选 `environment_id` |

仅新增表，无删除字段或历史数据迁移。发布前检查无进行中的 UI 自动化任务，备份源码及旧镜像，部署后后端和前端健康。

验证结果：10 项后端相关测试及前端构建通过。隔离环境和公网浏览器均验证新增、修改、删除、服务端持久化、刷新恢复选择和桌面视口、空名称校验；1440、1280、768、390、320px 无横向溢出，无页面异常。线上仅创建带时间戳的临时配置，验收后已删除，未向示例站点执行真实业务操作。
