## 建议与已执行修改

| 优先级 | 现场问题 / 风险 | 实施结果 |
| --- | --- | --- |
| 高 | 空首页分散注意力 | 全空时只显示起步引导和快捷入口；隐藏空内容面板与空访问记录。有数据后恢复工作摘要。 |
| 高 | 20项导航不利于日常使用 | 默认显示6个已授权的日常入口；允许显示全部并按账号记忆。搜索、直接URL、当前高级入口与权限校验保留。 |
| 高 | 编辑依赖反复手动保存 | 首次手动创建，之后停止输入1.5秒自动保存。保留手动保存和自动保存开关。 |
| 高 | 慢请求、失败和并发可能造成输入损失或误判 | 输入版本保护；请求期间继续编辑会使用新revision续存；503与409暂停自动重试，保留输入。提供人工重试与确认后读取服务器版本。 |
| 中 | 草稿状态不够可信 | 本机草稿写入失败时给出可见提示，区分尚未创建、等待保存、保存中、已保存、自动保存暂停。 |
| 中 | 首页恢复后仍显示错误 | 成功轮询时清除旧错误。 |
| 中 | 权限及跨设备细节 | 未授权账号不展示工作手记快捷入口；桌面折叠后转手机仍可展开完整导航。 |

本轮只发布上述前端改动，未混入工作区已有的认证、OA、小程序和全员圈未提交内容，也未删除用户数据。
