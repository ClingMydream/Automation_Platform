# 练习项目会话恢复修复与自检

2026-10-29。截图中的失败是练习Token失效后，业务壳仍保留、重新读取继续携带失效Token，导致页面无法恢复。并非通过反复刷新能解决。

## 修复

- 练习API统一识别401，同一客户端只触发一次会话失效状态。
- 所有业务读取与操作（含商品详情、订单详情）的401均切换到明确恢复页面。
- 提供“重新登录练习账号”入口，清理当前独立会话，重新展示正常登录流程。
- 平台Token、业务数据、未确认结算编号不清理；不延长失效Token、不绕过权限。
- 普通网络或业务错误继续显示读取/重试提示，不作为登录过期处理。
