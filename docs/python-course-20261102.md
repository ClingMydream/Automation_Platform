# 零基础学 Python 全课程整理

## 内容与入口

学习空间默认使用按链接学习，18 个分组、124 个单元：108 个字幕视频、15 个图文或章节总结、1 个测验说明。保留每讲原始链接，不复制完整视频或逐字稿。

每单元提供目标、要点归纳、原创离线 Python 示例、改写练习、折叠参考答案、测试工作联系和复习要求。原课测验题未获取或复制；平台提供的是原创自测练习。外部数据库、Redis、硬件、视觉模型及付费 API 的实际链路未验证，示例明确说明模拟或离线范围。

支持章节折叠、标题与章节搜索、上一讲/下一讲、单元独立草稿、保存到笔记本和手动确认完成。单元内容按需加载。保留首节旧 ID、旧笔记标题及历史学习入口，不清空旧数据。
