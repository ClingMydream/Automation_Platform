状态：实现与本地界面验收完成；完整业务回归 9 项通过、1 项受专用测试数据限制。尚未推送或替换线上自动化入口，不能标记十项全部通过。

## 范围与设计

仅包含 Web UI 自动化。界面自行设计，采用与 Cling 协调的浅色与柔和绿色；目录、步骤编排、结果和证据分区，独立滚动。手机屏幕改为上下布局，保留有限高度的用例和编辑区域。

- `StudioPage.jsx`：场景编辑、执行环境、历史记录、简报导出、截图/视频查看与下载。
- `StudioDataSets.jsx`：继续使用现有加密数据集，支持管理测试账号，保留脱敏密码。
- `studio_catalog.py`：十项内置场景与白名单动作；支持业务动作，以及点击、输入、键盘和页面断言。
- `studio_flows.py`：依照最新 Emote 页面重新实现的页面操作及结果断言。
- `studio_engine.py`：串行执行、24 小时登录态复用、真实结果记录、失败后隔离恢复、截图和录屏。
- `network_evidence.py`：按场景与步骤捕获浏览器网络异常，识别 HTTP、业务信封和嵌套业务失败，保存 URL、请求方法、Query、请求体、响应和耗时；不保存鉴权请求头，凭据脱敏。

新入口替换旧编辑器。旧 API、表结构及历史执行记录保留，不执行破坏性迁移。测试阶段新场景带 `studio-preview` 标签并在旧回归中停用；正式启用新入口时迁移这些平台自建场景。
