# 条件、循环与批量检查学习笔记

在接口测试中，接口往往会返回多条数据，例如多个预约、订单或一组请求结果。手工逐条查看不仅慢，也容易漏掉问题，所以需要用循环和条件做批量检查。

`for` 用于依次取出列表中的每一项，`if` 用于判断当前这一项是否符合规则。可以把 `for` 理解为“逐条检查”，把 `if` 理解为“检查标准”。

```python
status_codes = [200, 200, 404, 500]

for code in status_codes:
    if code >= 400:
        print("发现失败状态码：", code)
```

这里 `status_codes` 是列表，循环每次把其中一个状态码保存到 `code` 变量中。当状态码大于或等于 `400` 时，说明请求失败，就输出异常状态码。最终会输出 `404` 和 `500`。

条件常用写法：

```python
code == 200   # 状态码是否等于 200
code != 200   # 状态码是否不是 200
code >= 400   # 是否为客户端或服务端错误
code < 300    # 是否属于成功或重定向前的范围
```

`if` 后的条件只有结果为 `True` 时，缩进的代码才会执行。

除了找异常，还可以统计成功和失败的数量：

```python
status_codes = [200, 200, 404, 500, 201]

success_count = 0
failed_count = 0

for code in status_codes:
    if code < 400:
        success_count += 1
    else:
        failed_count += 1

print("成功：", success_count)
print("失败：", failed_count)
```

列表里也可能保存多个字典。接口返回预约列表时，每一条预约通常是一个字典：

```python
bookings = [
    {"bookingid": 8, "name": "张三"},
    {"bookingid": 12, "name": "李四"},
    {"bookingid": 15, "name": "王五"}
]

for booking in bookings:
    if booking["bookingid"] > 10:
        print(booking)
```

这段代码先遍历 `bookings` 列表，每次得到一条 `booking` 字典；再通过 `booking["bookingid"]` 取出编号，只输出编号大于 `10` 的记录。

批量检查的思路是：先确认接口返回的是列表还是字典；列表用 `for` 逐条读取，字典用键取值；然后用 `if` 判断结果是否符合预期。发现异常时，应输出能帮助定位的信息，例如记录 ID、状态码和响应内容，而不是只输出“失败”。

```python
for booking in bookings:
    booking_id = booking.get("bookingid")
    if booking_id is None:
        print("异常：缺少 bookingid", booking)
    elif booking_id <= 10:
        print("不符合筛选条件：", booking_id)
```

这样写可以把批量数据检查变成清晰、可重复执行的规则，也是接口自动化测试的基础。
