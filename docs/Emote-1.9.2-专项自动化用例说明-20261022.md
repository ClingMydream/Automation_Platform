# Emote 1.9.2 专项自动化

新增 16 条独立用例，覆盖指定八类功能。平台「Emote UI 自动化」点击「1.9.2 专项」，选择已有测试数据集即可运行，也可在用例列表单独执行。

| 范围 | 检查内容 |
|---|---|
| 昵称校验 | 空闲昵称 success=true/data=null、重复昵称 success=false/code=409、敏感昵称原因及禁用保存、防抖等待禁止保存 |
| 删除动态 | 首页本人私密动态、个人收藏页本人动态、原野指定本人公开测试动态，核对删除接口与列表即时移除 |
| 收藏 | 收藏、个人列表出现、取消收藏、个人列表移除 |
| 拉黑 | 测试用户拉黑后当前原野不再展示、黑名单解除及列表移除 |
| 私聊 | 好友备注保存及顶部更新、举报本轮测试消息后弹窗关闭 |
| 系统消息 | 单条已读持久化及红点消退、全部已读角标消退 |
| 意见反馈 | 真实提交、成功状态、约两秒后收起 |
| 注销 | 专用账号 B 申请后退出、冷静期登录提示、取消后进入首页 |

## 安全与前置条件

- 使用原测试数据集，后台解密并传给执行器，密码与 Token 不写进结果报告。
- 默认不执行注销。每次必须单独勾选授权，且只允许平台预览实际连接已知 emote-test API、账号 B 与 A 不同且不是管理员、原本不在冷静期。自填线上地址不允许注销专项。
- 注销最终恢复校验失败，整轮立即停止，报告要求人工处理，不继续写操作。
- 拉黑只操作数据集账号 B，并恢复既有关系；本来已经拉黑则保留原状态并标为受限。
- 备注测试后恢复原值；已接受写入但无法确认恢复则停止整轮。
- 默认聊天好友「霖感小秘书」，可在数据集专项配置中调整。测试消息包含当前时间戳；仅举报本轮消息，注明自动化测试。
- 删除首页、个人收藏页使用本轮创建的本人私密测试帖。原野不自动发布公开内容，必须在数据集指定可丢弃的本人公开测试帖 ID 并勾选确认；否则标为受限。
- 系统已读需要真实未读消息；不足时标为受限，不伪造通过。
- 新建私密帖是 API 准备的夹具，不代替已有发帖 UI 流程，不宣称覆盖 UI 发帖。
- 除删除用例明确删除测试帖外，私密测试记录保留。反馈与举报会真实写入测试环境。

## 执行及报告

- 专项写操作不自动重试，防止重复发送或重复建数据。
- 一条失败仍继续后面的用例，账号恢复失败等安全错误除外。
- 报告分别统计通过、失败、前置受限、未执行；每条结果保留失败原因、关键检查记录、视频和关键截图。
- 真实后端契约与预期不符时报告失败，不通过放宽断言跑绿。
- 初次新增用例后记录安装版本，后续不会覆盖用户编辑或恢复用户已删除的专项用例。

8 项回归测试通过：安装幂等且保留编辑/删除、场景白名单、范围选择与单次授权、注销域名/账号边界、诊断脱敏、失败/受限后继续且不重试、恢复不确定时停止、退出后无旧 Token 仍可登录恢复。
前端报告回归及生产构建通过。远程专项真实执行结果见平台对应执行记录；受限项目不记为通过。
