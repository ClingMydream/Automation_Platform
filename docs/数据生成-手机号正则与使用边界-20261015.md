# 手机号生成规则修正

- 优先满足常见手机号正则：^1[3-9][0-9]{9}$，11 位纯数字。
- 生成器使用内置常见号段，同一批次去重；没有对运营商分配状态进行查询，不能保证号码不属于真人。
- API 明确返回 allocation_status=unknown、potentially_real=true。sms_capable=false 表示本工具没有短信发送能力，不表示号码在现实中不可接收短信。
- 页面显示碰撞风险，要求仅用于隔离测试，不拨打、不发送真实短信。
- 需验证真实短信时应另用自有或受控号码池，不能将随机号用于发送。
- 保留历史 TEST-PHONE、000 开头批次的读取和备注编辑；新生成均为正常格式。
- 本地 11 项测试及前端构建通过；号码正则、未知分配状态、批次增删改查、备注、隔离、冲突及无效号码拦截均覆盖。
