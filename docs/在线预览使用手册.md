# Emote 在线预览使用手册

## 这个模块用来做什么

在线预览用于把 Emote 的指定远程分支构建成公网可访问的网页版本，方便测试、验收和向同事展示。它只读拉取远程仓库，**不会执行提交、合并、变基或推送操作**。

## 操作步骤

1. 打开 cling 的「个人成长 / 在线预览」。
2. 在“选择远程分支”下拉框中选择要验证的分支。
3. 点击“同步最新代码”。系统会将任务提交给 Jenkins。
4. 观察“构建进度”：依次会读取远程代码、安装依赖、生成网页预览、适配预览地址并发布。
5. 当构建状态为“构建成功”后，查看版本核验提示。显示“线上预览已与远程最新代码一致”才表示远程最新提交已真正上线。

构建期间，线上仍保留上一次成功发布的预览，因此可继续访问，不会出现空白页面。

## 两种预览方式

- **手机应用预览**：另开一个独立页面，用 390×844 手机边框显示 Emote，适合检查手机端布局和交互。
- **网页调试模式**：另开原始预览网页，适合在电脑浏览器中使用开发者工具定位问题。

## 如何判断是否同步成功

不要只看 Jenkins 的“构建成功”。请同时看版本核验区域：

- **线上预览已与远程最新代码一致**：分支和提交号均相同，已经同步完成。
- **有新代码**：远程分支已有新提交，需要再次同步。
- **线上预览属于其他分支**：当前线上仍显示另一个分支，应切回目标分支后同步。
- **尚未检测到版本清单**：旧版本是在版本核验功能上线前发布的；重新同步一次即可生成清单。

## 常见问题

### 点击同步后没有立即变更

同步先进入 Jenkins 队列。点击“刷新状态”可读取最新进度；构建完成后刷新预览页面即可看到新版。

### 构建失败会不会影响正在使用的预览

不会。系统只有在网页构建完成后才替换线上文件；失败时继续提供上一次成功版本。

### 为什么预览接口连接的是测试环境

在线预览构建时固定注入 Emote 测试后端 `https://www.inxpiration.cn/emote-test/api`，避免使用开发者电脑的局域网地址。
