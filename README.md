# Cling 个人工作空间

React / Ant Design 前端与 FastAPI 后端，覆盖自动化测试、个人工作记录、自考和效率工具。

## 功能入口

- 测试中心：Emote UI 自动化、全员圈统计、接口工作台、Emote 测试环境（网页预览 / 构建打包 / 安装包）。
- 个人成长：自考题库、命令手册、临时效果、工作手记（工作日志 → 日报 → P/R/O 周报）。
- 效率工具：数据生成、文件快传、图片工具、文本工具（JSON / 转码）。
- 系统配置：集成配置、用户管理、小程序 OA 管理。

组合入口只收拢导航，各子功能仍使用独立权限和原有 `?module=` URL。无权限的页签不会展示。

学习空间、酒店练习项目和莓好审批网页版已下线。旧接口不再挂载；独立酒店、审批及 Booker 代理地址返回 410。已有数据库历史表和存储备份保留，不自动删除历史资料。自考题库与小程序 OA 不受影响。

## 开发与验证

- 前端：在 `frontend/` 安装依赖后运行 `npm run dev`；`npm run build` 构建。
- 后端：按 `backend/requirements.txt` 安装依赖，使用 `uvicorn app.main:app` 启动。
- 隔离自测：见 [前端回归说明](frontend/tests/platform-audit/README.md)。测试不能改为生产地址。
- 小程序：微信开发者工具导入根目录，通过 `project.config.json` 加载 `miniprogram/`；微信凭据仅在服务器配置。
- 部署、备份与环境变量：见 [部署说明](deploy/README.md)，生产配置不写入仓库。

`output/` 保存本地测试产物和清理前源码快照，不属于运行时模块。不要直接删除 Git 工作树或服务器数据卷。
